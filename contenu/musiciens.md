# Les Musiciens

Ajouter un bloc de niveau 2 par membre après validation de sa présentation et, le cas échéant, des droits sur son portrait. Indiquer Instrument dans une puce, puis raconter le choix de cet instrument dans un paragraphe. Une Photo locale dans assets/musiciens/ est facultative. Sans fiche validée, la page affiche un message d’attente. Ce préambule n’est pas publié.
