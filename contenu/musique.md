# Musique du site

Un titre de niveau 2 par morceau ; déplacer les blocs change leur ordre. Déposer les MP3/WAV autorisés dans src/assets/audio/ et les déclarer avec Fichier : assets/audio/nom-du-morceau.mp3. Le lecteur joue ces fichiers locaux, jamais une URL YouTube. Mettre à jour les crédits et l’empreinte en remplaçant un fichier.
